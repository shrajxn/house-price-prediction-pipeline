# House Price Prediction Pipeline

## Project Goal
Build a complete supervised learning preprocessing and feature engineering pipeline for house price prediction using the Ames Housing dataset.

## Objectives
- Practice professional ML workflow
- Perform comprehensive EDA
- Build reusable preprocessing utilities
- Create feature engineering pipelines
- Maintain Git version history
- Develop production-style project structure

## Dataset
Source:
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

## Project Structure
- `data/` → raw and processed datasets
- `notebooks/` → exploration and experimentation
- `src/` → reusable Python modules
- `reports/` → visualizations and metrics
- `models/` → trained models and artifacts

## Workflow
1. Data Loading
2. Exploratory Data Analysis
3. Data Cleaning
4. Feature Preprocessing
5. Feature Engineering
6. Pipeline Integration
